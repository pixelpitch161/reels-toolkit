# Where the built-in fonts come from

Every file here was downloaded from the font's official repository at a pinned commit and checked with
`git hash-object <file>` against the blob id below. All four fonts are under the SIL Open Font License 1.1; its text
travels with them in `OFL-IBM-Plex.txt`.

No emoji font is built in: no official monochrome Noto Emoji has the harp (U+1FA89) yet, so the app leaves emoji to
the PC's own fonts.
