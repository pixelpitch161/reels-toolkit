# Ideas & status board

The single place that tracks every reel. **Keep this file short**: one row per video, a one-line note. Everything
else lives in its own file, so sessions only read what they need:

| What | Where |
|---|---|
| One file per idea: the approved entry, beat sheet, flags, design changes, full board history | `docs/ideas/NN-slug.md` (linked from each row) |
| BALLFIGHT series rules (title card, HUD, colours, crossovers, retired fighters, …) | `docs/ballfight/RULES.md` |
| What each video taught us | `docs/log/<project>.md` (index: `docs/LOG.md`) |
| How every video is made | `docs/PLAYBOOK.md` |

**A production session reads:** its row here, its idea file, the series rules if it has a series, `docs/PLAYBOOK.md`,
and its own project's log (plus another project's log only when reusing that project). Not the whole archive.

Each production session updates **its own row**: when it starts, sends a draft, gets feedback and delivers. Keep the
"Last feedback / next step" cell to one line; put details in the idea file's history and the project log.

**Statuses:** `idea` → `approved` → `in production` → `review` → `done` (or `parked`)

## Adding a new idea

Create `docs/ideas/NN-slug.md` (next free number) from this template and add a row to the board linking to it:

```
# N. Title
- **Hook:** "BIG NUMBER OR QUESTION" (in the first 2 s)
- **Science / mechanic:** what drives it (with a source if it's a fact)
- **Music:** what drives tempo, pitch or rhythm, and which music (original or public domain)
- **Scene:** the environment, the subject, and what escalates
- **Payoff / ending:** the "all at once" climax, then a loop back to the opening
```
