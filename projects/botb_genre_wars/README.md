# Battle of the Bands: Genre Wars (IDEAS #25)

A Battle of the Bands episode on the #20 engine. The four teams are genres, and the song itself morphs toward
whoever is winning: every genre plays the same original song (A minor, 118.03 BPM, | Am | F | Dm | E |, one 8-bar
melody) in its own style, each genre's volume follows its share of the stage, and the drums and the melody follow
it steeply, so the groove and the tune belong to the leader. When the lead changes you hear the genre change (plus a
stinger in the new leader's style) and the stage lights change with it. A knocked-out genre dives in pitch and drops
out; the winner's style takes the whole song for the solo. 61.0 s; the wall cracks back to empty exactly at 61.0 =
frame 0.

| genre | engine team (unchanged) | its arrangement | stage mood when it leads |
|---|---|---|---|
| ORCHESTRA (gold) | SAND: a cascading wall of sound pours from the hopper | timpani + cymbal, galloping cellos, violin pad + brass stabs, french horns | warm gold wash, gold searchlights, rising motes |
| ROCK (red) | BALL: smashing ricochets | kit, pick bass, 3-3-2 power chords, distorted lead guitar | red wash, pyro jets from the front cannons on every bar |
| EDM (cyan) | RIPPLE: a ring on every beat | four-on-the-floor, off-beat sub bass, supersaw stabs, saw lead | cyan wash, lasers that step on every beat |
| JAZZ (blue) | VINE: improvised wandering lines | swung ride + brushes, walking upright bass, rootless piano comping (Am9 / Fmaj9 / Dm9 / E7b9), tenor sax | blue haze over the boards, soft spot cones |

## Reuse

- Engine: `projects/battle_of_the_bands/battle.py`, imported unchanged (`episode.py` appends its folder to
  `sys.path`, so this project's own `sim.py`, `scene.py` etc. win). The genres are the four engine teams with new
  names and colours; balance, rules and arena are #20's.
- Copied and adapted: `scene.py` (genre colours, pyro cannons, laser emitters), `render.py` (genre FX + mood lights,
  new scoreboard), `focus_check.py`. New: `music.py` (four arrangements + layer gating), `audio.py` (four voice sets,
  per-layer calibration, per-genre leveler), `timeline.py` (lead changes, mood, caption scheduler).
- Shared reelkit: `ui.share_bar` + impact captions, `audio.thud`, `loopcheck`, `flashcheck`, `safezone`, `levels`,
  `sheet`, `video`.

## Build

```bash
python seed_search.py 0 600 --stop 5   # rank honest seeds (stops once 5 fit)
python sim.py                          # episode.SEED -> sim.npz + sim_state.pkl
python timeline.py                     # print knockouts, lead changes, captions
python audio.py --solos                # -> audio.wav (+ check/solo_<genre>.wav: each stem alone, 8 bars)
python focus_check.py                  # LED wall + props CoC on all 1830 frames (expect 0)
python -m reelkit.sheet render.py test/sheet.png 0.5 3.3 12.5 19.6 24.45 29.2 34.2 43.8 53.4 57 60.55
python -m reelkit.safezone render.py --step 0.25
python -m reelkit.loopcheck render.py audio.wav
python -m reelkit.video render.py audio.wav botb_genre_wars.mp4
python -m reelkit.flashcheck botb_genre_wars.mp4
```

| file | what |
|---|---|
| `episode.py` | the line-up (genre names + colours on the four engine teams), 118.03 BPM grid, bell on bar 10, seed |
| `seed_search.py` | runs seeds in parallel and ranks their stories for 61 s (nothing is ever hand-edited) |
| `sim.py` | runs the chosen seed for 61 s and caches it |
| `timeline.py` | video time = sim time; smoothed shares, lead changes, the stage mood, the caption scheduler (events + fillers so the text changes every few seconds) |
| `music.py` | the song, the four arrangements (drums / bass / harmony / lead per genre), move gating -> one note list; share -> per-layer gains |
| `audio.py` | the voices, per-layer calibration (phone-weighted, so each stem is balanced alone), per-genre + band levelers, stingers, power-downs, bell, crowd, crack, seam riser; circular buses |
| `scene.py` | #20's stage re-themed: genre colours, props in their genre's colour, pyro cannons, laser emitters |
| `render.py` | #20's renderer + genre FX (pyro, lasers, spot cones + haze, gold motes), mood wash, scoreboard with instruments |
